# Task 3 — Secure Coding Review

## 💰 Project: Expense Tracker

This repository contains my work for **Task 3: Secure Coding Review**.

For this task, I selected my **Python Expense Tracker** project and performed a security review of the source code. The review included both **manual code analysis** and **automated security testing using Bandit**.

---

## 🎯 Objective

The main objectives of this task were:

- Review the existing source code for security issues.
- Identify potential weaknesses through manual code review.
- Perform automated security scanning using Bandit.
- Improve the code based on the review.
- Document the security findings and improvements.
- Maintain evidence of the security review.
